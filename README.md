# Precimax — site demonstrativo\n\nSite fictício de usinagem industrial em HTML, CSS e JavaScript.\n\n## Publicação\nEnvie `index.html`, `style.css`, `script.js` e a pasta `assets` para um repositório separado chamado `precimax-demo`. Ative GitHub Pages na branch principal, pasta raiz.\n\n## Antes de usar com cliente\n- Precimax e todos os contatos são fictícios.\n- Em `script.js`, troque `5511900000000` pelo WhatsApp real (55 + DDD + número).\n- Troque telefone, e-mail, localização, textos e imagens por informações autorizadas da empresa.\n- O formulário abre uma mensagem pré-preenchida no WhatsApp; não salva dados em banco.\n- O vídeo de fundo está preparado. Adicione um MP4 leve chamado `usinagem-loop.mp4` dentro de `assets` para ativá-lo. Sem o MP4, aparece a arte de capa e o fundo de imagem.\n- As fotos de serviço são imagens externas e precisam de internet.\n
